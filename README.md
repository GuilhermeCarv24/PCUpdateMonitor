# 🖥️ PC Update Monitor

Um monitor de atualizações do Windows desenvolvido em C# e .NET 10.

O objetivo do projeto é verificar se existem atualizações do Windows disponíveis e informar o usuário diretamente pelo terminal.

## 🚀 Funcionalidades

- Verificação de atualizações disponíveis do Windows
- Contagem das atualizações encontradas
- Exibição do nome das atualizações disponíveis
- Mensagem informando quando o sistema está atualizado
- Tratamento de erros durante a consulta
- Utilização da API nativa do Windows Update

## 🛠️ Tecnologias

- C#
- .NET 10
- Windows Update Agent (WUA)
- Visual Studio Code
